# Игрушкин — магазин игрушек

Учебный одностраничный сайт: магазин игрушек «Игрушкин». HTML, CSS и чистый JavaScript в трёх файлах, без библиотек и сборки, кнопки и карточки в стиле [uiverse.io](https://uiverse.io), фото с [Unsplash](https://unsplash.com).
Сделан для уроков программирования с детьми, код подробно прокомментирован на русском. Стиль — яркий и весёлый, цвет — зелёный.

**Открыть сайт:** https://si0683.github.io/ToyStore/

## Что на сайте

- Главный экран: название, слоган, большое фото, кнопка «Купить».
- О нас, 3 преимущества, 3 карточки «Любимые игрушки» с фото и ценами.
- Блок с кнопкой действия и контакты: телефон, почта, адрес, ВК и MAX.
- Окно заказа с проверкой полей, корзина, светлая и тёмная тема, плавное появление блоков, салют после заказа.
- «Лаборатория сайта»: 5 настроек в начале `style.css` и 5 в начале `script.js` — их меняют дети на уроке.

## Файлы

```
index.html     — разметка: шапка, 6 блоков сайта, подвал, окно заказа
style.css      — оформление: лаборатория, цвета, кнопки, карточки, анимации, телефон
script.js      — поведение: лаборатория, меню, появление блоков, корзина, форма, тема, салют
PROMPT.md      — промт для нейросети: подробное ТЗ + полные исходники
PROMPT_QWEN.md — инструкция для урока: Qwen быстро берёт готовые файлы по ссылкам, и они вставляются в CodePen
AGENTS.md      — правила для ИИ-агентов (PROMPT.md обновляется вместе с сайтом)
codepen/index.pen.html — готовый HTML для CodePen (создаётся автоматически)
tools/build.py — обновляет исходники в PROMPT.md и файл codepen/index.pen.html
```

После любого изменения кода:

```bash
python tools/build.py
```

## Запуск у себя

```bash
python -m http.server 8000
```

Откройте http://localhost:8000. Или просто откройте `index.html` в браузере.

## CodePen

Вставьте `codepen/index.pen.html` в окно HTML, `style.css` — в CSS, `script.js` — в JS. Пошагово для урока с Qwen — в [PROMPT_QWEN.md](PROMPT_QWEN.md).
