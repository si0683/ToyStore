# AGENTS.md — правила для ИИ-агентов

Учебный сайт для уроков программирования с детьми. Перед работой прочитай `README.md` и `PROMPT.md`.
Шесть сайтов сделаны по одному шаблону: Pizzeria, GameStore, ClothesShop, Confectionery, ToyStore, DanceSchool (`D:\8Lending\sites\tetrika`). Общие части (разметка блоков, разделы 1–8 CSS, весь JS) у них одинаковые — исправил ошибку в одном, повтори в остальных. Различаются тексты, фото, цвета и шрифты; все пять стилей (раздел 9 CSS, `.style-<id>`) есть в каждом сайте и включаются строкой `LAB.style`.
Общий промт урока на все 6 сайтов (выбор темы, стиля и цвета) — отдельный репозиторий `CreateSite01PROMT` (https://github.com/si0683/CreateSite01PROMT, папка `D:\8Lending\sites\tetrika\CreateSite01PROMT`): меняешь адреса, `LAB` или список изменений — перезапусти генератор, он обновит и его.

## Главное правило: PROMPT.md всегда соответствует сайту

- Любое изменение текстов, цветов, блоков, поведения — в том же изменении отрази в `PROMPT.md` (исправленный баг — с пометкой ⚠️).
- В конце `PROMPT.md` — полные исходники между `SOURCES:START` и `SOURCES:END`. Руками не править: после любого изменения `index.html`, `style.css` или `script.js` запусти `python tools/build.py` (он же пересобирает `codepen/index.pen.html`).
- `PROMPT_QWEN.md` — инструкция для урока. Весь промт — ОДИН блок ````text в начале файла (создание сайта + 10 изменений через лабораторию), для детей он выглядит как просьба создать сайт, файлы поданы как «шаблон проекта». Поменял настройку лаборатории — обнови список в промте и таблицу «10 изменений». Строка «было» должна встречаться в своём файле ровно один раз (её ищут через Ctrl+F).
- Перед коммитом: номер `?v=` в `index.html` увеличен (у CSS и JS одинаковый), `python tools/build.py` запущен.

## Ограничения кода

- Только HTML, CSS и чистый JavaScript в трёх файлах, всего не больше 1000 строк. Без библиотек, фреймворков, TypeScript, React, сборки.
- Простой код для детей: функции без классов, подробные комментарии на русском. Лаборатория: 5 настроек в `:root` в начале CSS и объект `LAB` в начале JS (первые строки — `style` и `color`, их меняет общий промт); значения по умолчанию = обычный сайт.
- Фото — только прямые ссылки `images.unsplash.com` (бесплатная лицензия, не `plus.unsplash.com`).

## Проверка

`python -m http.server 8000` в папке сайта → http://localhost:8000. Проверь ширину 320, 375, 768 и 1280 px (нет горизонтальной прокрутки), меню-бургер, тему, корзину, окно заказа (ошибки полей, Esc, отправка), фото. В консоли не должно быть ошибок.
