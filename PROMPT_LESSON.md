# Промт для урока: сайт по выбору ученика

Один промт на все шесть сайтов. Ученик выбирает тему, стиль и цвет — меняет **три строки** в начале промта, а Qwen сам берёт готовый шаблон нужного сайта. Скопируйте промт **одной кнопкой** (два квадратика в правом верхнем углу блока).

## Промт

<!-- Для ИИ-агентов: ВЕСЬ промт — один блок ````text. Не делить на несколько блоков.
     Ссылки на шаблоны — полные, отдельным блоком на каждую тему: Qwen плохо подставляет части адреса.

````text
Ты — дизайнер сайтов. Создай простой одностраничный сайт для CodePen.

МОЙ ВЫБОР (меняю только эти три строки):
Тема сайта: пиццерия
Стиль сайта: уютный
Основной цвет сайта: красный

Можно выбрать:
тема — пиццерия / магазин с видеоиграми / магазин одежды / кондитерская / магазин игрушек / школа танцев;
стиль — простой и аккуратный / яркий и весёлый / тёмный / современный / уютный;
цвет — красный / синий / зелёный / оранжевый / фиолетовый.

На сайте должны быть блоки:
1. Главный блок: название сайта, короткий слоган, большая картинка по теме, заметная кнопка действия.
2. О сайте: 2–3 предложения о том, что это за сайт и чем он полезен посетителю.
3. Преимущества: 2–3 причины выбрать именно нас.
4. Товары или услуги: 2–3 карточки с картинками.
5. Блок с кнопкой действия: «Заказать», «Купить» или «Записаться».
6. Контакты: телефон, почта, адрес, соцсети ВК и MAX и короткий призыв связаться.
Сайт простой и аккуратный, текст короткий, цвета хорошо сочетаются, дизайн как у профессионалов, сайт работает на телефоне. Код без ошибок, работает с первого раза, всего не больше 1000 строк.

Должно получиться ровно 3 файла, как три окна в CodePen: HTML (index.pen.html), CSS (style.css), JS (script.js).
Только обычный HTML, обычный CSS и ЧИСТЫЙ JavaScript. НЕ используй TypeScript, React, JSX, Vue, Next.js, npm, import и export.

Сделай сайт по моему готовому шаблону: в нём уже есть дизайн, картинки и тексты. У каждой темы свой шаблон.
Найди ниже блок «ТЕМА: …» с моей темой из «МОЙ ВЫБОР» и бери файлы ТОЛЬКО по трём ссылкам этого блока. Ссылки других тем не открывай.
Если моей темы нет в списке, напиши: «Такой темы нет, выбери тему из списка».

ТЕМА: пиццерия

Как выдавать код:
- Первой строкой первого ответа напиши проверку: «Тема: …, шаблон: …, стиль: …, цвет: …». В «шаблон» впиши слово из ссылки, например Pizzeria.
- Код каждого файла возьми из шаблона полностью, без сокращений и без других изменений, кроме двух строк стиля и цвета (ниже). Шаблон уже на чистом JavaScript — не переводи его на TypeScript или React.
- Стиль и цвет из «МОЙ ВЫБОР» поставь только в JS: в самом начале файла, в блоке LAB, есть две строки:
  style: '…',
  color: '…',
  Впиши в них мой стиль и мой цвет. Больше ничего в коде не меняй.
- Отвечай сразу, без долгих рассуждений и без объяснений кода.
- По одному файлу за ответ: сначала HTML, после моего «дальше» — CSS, после следующего «дальше» — JS.
- Перед каждым блоком кода напиши одну строку:
  «Файл 1 из 3 — HTML (index.pen.html). Вставьте в окно HTML и напишите: дальше»
  «Файл 2 из 3 — CSS (style.css). Вставьте в окно CSS и напишите: дальше»
  «Файл 3 из 3 — JS (script.js). Вставьте в окно JS — сайт готов!»
- Если файл не помещается в один ответ, остановись в конце строки. После «дальше» продолжи со следующей строки новым блоком кода.

Когда сайт будет готов, я буду просить изменения. Меняй только блок «ЛАБОРАТОРИЯ САЙТА» в начале CSS (:root) или в начале JS (LAB), одно значение на одну просьбу. Отвечай сразу и коротко: в каком файле менять, строка «было» и строка «стало» в блоке кода. Идеи для изменений:
1. Поменяй стиль на тёмный → style: 'тёмный', (JS)
2. Перекрась сайт в синий → color: 'синий', (JS)
3. Переименуй сайт → siteName: 'Новое название', (JS)
4. Напиши на наклейке «Скидка 50%» → sticker: 'Скидка 50%', (JS)
5. Включи дождь из эмодзи → fallingEmoji: '⭐', (JS)
6. Включи тёмную тему → startDark: true, (JS)
7. Поменяй сообщение после заказа → thanksText: 'Спасибо, ждём вас снова! 😊', (JS)
8. Сделай второй цвет жёлтым → --accent: #facc15; (CSS)
9. Сделай углы острыми → --radius: 0px; (CSS)
10. Поменяй шрифт заголовков на Comic Sans → --font-title: 'Comic Sans MS', cursive; (CSS)
11. Сделай главный заголовок огромным → --hero-title: 7rem; (CSS)

Начинай: строка проверки и файл 1 — HTML.
````

> **Только для преподавателя.** Для детей промт выглядит как задание дизайнеру с выбором темы, стиля и цвета. На самом деле в нём ссылки на «шаблоны проекта» — готовые сайты, и Qwen берёт нужный без изменений, меняя только две строки стиля и цвета. Поэтому он отвечает за минуты, а сайт гарантированно работает.

## Как менять выбор на уроке

1. Вставьте промт в поле ввода Qwen, но **не отправляйте**.
2. Вместе с учеником поменяйте три строки в блоке «МОЙ ВЫБОР» — слова пишите **как в списке «Можно выбрать»**:
   ```
   Тема сайта: кондитерская
   Стиль сайта: яркий и весёлый
   Основной цвет сайта: зелёный
   ```
3. Отправьте. Первая строка ответа Qwen — проверка «Тема: …, шаблон: …». Шаблон должен совпадать с таблицей:

| Тема | Шаблон | Готовый сайт (запасной вариант) |
|---|---|---|
| пиццерия | `Pizzeria` | https://si0683.github.io/Pizzeria/ |
| магазин с видеоиграми | `GameStore` | https://si0683.github.io/GameStore/ |
| магазин одежды | `ClothesShop` | https://si0683.github.io/ClothesShop/ |
| кондитерская | `Confectionery` | https://si0683.github.io/Confectionery/ |
| магазин игрушек | `ToyStore` | https://si0683.github.io/ToyStore/ |
| школа танцев | `DanceSchool` | https://si0683.github.io/DanceSchool/ |

Стиль и цвет подходят к любой теме: например, тёмная пиццерия или яркая школа танцев. Любую комбинацию можно поменять и после создания сайта — изменения 1 и 2.

## На уроке

**Шаг 1.** Откройте [chat.qwen.ai](https://chat.qwen.ai), новый чат.

**Шаг 2. Режим — самое важное для скорости:**
- ❌ **не включайте «Web Dev» / «Веб-разработка» / «Artifacts»**: там Qwen переписывает всё на React (`.tsx`);
- ❌ **выключите «Мышление» (Thinking)**: иначе долгие рассуждения;
- ✅ **включите «Поиск» (Search / веб-доступ)**: без него Qwen не откроет ссылки.

**Шаг 3.** Вставьте промт, поменяйте «МОЙ ВЫБОР», отправьте.

**Шаг 4.** Откройте [codepen.io/pen](https://codepen.io/pen/) и соберите сайт из трёх ответов:

| Ответ Qwen | Куда вставить в CodePen | Что написать Qwen потом |
|---|---|---|
| Файл 1 из 3 — HTML | окно **HTML** (в CodePen 2.0 — файл `index.pen.html`) | `дальше` |
| Файл 2 из 3 — CSS | окно **CSS** (файл `style.css`) | `дальше` |
| Файл 3 из 3 — JS | окно **JS** (файл `script.js`) | — |

**Шаг 5. Проверьте стиль и цвет.** В окне JS в самом начале должны стоять строки выбора, например `style: 'яркий и весёлый',` и `color: 'зелёный',`. Если Qwen оставил старые — поправьте их руками: сайт сразу перекрасится.

**Шаг 6. Меняем сайт.** Ученик пишет Qwen просьбу своими словами или номер из списка изменений. Qwen отвечает «было → стало»: откройте нужное окно (CSS или JS), `Ctrl+F`, найдите строку «было» и замените на «стало».

## Если что-то пошло не так

| Что случилось | Что сделать |
|---|---|
| В строке проверки не тот шаблон | Напишите: `Ты взял не тот шаблон. Моя тема — кондитерская: возьми три ссылки из блока «ТЕМА: кондитерская» и начни заново с HTML.` |
| Стиль или цвет не поменялись | Поправьте строки `style:` и `color:` в начале окна JS сами (шаг 5). Неизвестное слово сайт пропускает и оставляет родной стиль. |
| Qwen долго «думает» | Выключите «Мышление», начните новый чат. |
| «Не могу открыть шаблон» | Включите «Поиск» и отправьте промт заново. |
| Qwen выдал `.tsx`, React или TypeScript | Выключите «Web Dev», новый чат. Или: `Нужен чистый JavaScript — возьми script.js из шаблона как есть.` |
| Qwen остановился посреди файла | Напишите `дальше` и вставьте продолжение в конец окна. |
| Qwen пишет свой код или «улучшает» | Напишите: `Возьми код из шаблона без изменений, поменяй только style и color.` |
| В CodePen ошибка `has already been declared` | В окно HTML попал лишний `<script>`. Вставьте файл 1 заново. |
| Ничего не помогает | Покажите готовый сайт из таблицы выше. |
